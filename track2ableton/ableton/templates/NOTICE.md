# Template provenance

`live12_templates.xml.gz` is generated by `tools/build_templates.py` from Ableton Live 12.4.x sets
saved by Ableton Live itself, published in https://github.com/aboard-io/stellate
(`tools/ableton/donor/`), MIT License, Copyright (c) 2026 Paul Ford.

Only structure is kept: tracks are emptied, clips and notes cleared, preset references and the
donor's local file paths removed. Device parameter values that this tool does not set keep the
donor's values (they are ordinary Live settings, not samples or presets).

## Parameter encodings used by the writer, and how sure we are

| Parameter | Encoding assumed | Basis |
|---|---|---|
| Compressor `Threshold` | linear gain (1.0 = 0 dB) | observed default value 1 |
| EQ Eight `Mode` | 0 LowCut48, 1 LowCut12, 2 LowShelf, 3 Bell, 4 Notch, 5 HighShelf, 6 HighCut12, 7 HighCut48 | consistent with the default bands seen in the donor (2/3/3/5); not confirmed by Ableton |
| Time signature | `log2(den)*99 + (num-1)`, 4/4 = 201 | only 4/4 observed |
| Reverb `DecayTime`, `PreDelay` | milliseconds | observed 1200 / 2.5 |
| Drift / Wavetable envelope times | seconds | observed 0.001 .. 0.6 |
| Utility `StereoWidth` | 1.0 = 100 % | observed default 1 |
| `OriginalCrc` | written as 0 | Live's CRC algorithm is unknown |

Nothing here was verified by opening a generated file in Live inside this project's CI; see the
README for the manual verification step.
