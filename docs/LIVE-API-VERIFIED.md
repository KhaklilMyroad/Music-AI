## Things that DIFFER from the requested list (read first)

1. **`Track.insert_device`** exists but is **Live 12.3+** only (AJS "Available since Live 12.3"; absent in 11.0). Signature `insert_device(DeviceName: str, DeviceIndex: int = -1)` -- device's *UI name* string first, index second; returns the device. Not used by any Ableton script. Same method exists on `Chain`. Guard with `hasattr`.
2. **`Track.create_midi_clip(start_time, length)`** -- Live **12.2+** (AJS). **`Track.create_audio_clip(path, time)`** -- 12.x, exact minor not verified (probably 12.2). Both are **arrangement** clip creators with positional-only args (`arg2, arg3` in the signature, so keyword calls will fail).
3. **`ClipSlot.create_audio_clip(path)`** -- exists in 12.4, absent in 11.0; minimum 12.x minor **NOT verified**.
4. **Notes API argument order**: `get_notes_extended(from_pitch, pitch_span, from_time, time_span)` and `remove_notes_extended(...)` same order; legacy `get_notes(from_time, from_pitch, time_span, pitch_span)` / `remove_notes` use a DIFFERENT order. Ableton's scripts always pass keywords (`from_time=, from_pitch=, time_span=, pitch_span=`) -- do the same.
5. **`Live.Clip.MidiNoteSpecification`** has no signature in any dump. Keyword names verified from Ableton usage: `pitch, start_time, duration, velocity, mute` (+ `probability, velocity_deviation, release_velocity` via MxDCore `**note_dict`). Required: `pitch, start_time, duration`.
6. **`Clip.start_time` is READ-ONLY**; **`Device.is_active` is READ-ONLY** (toggle via the "Device On" parameter).
7. **`Song.create_scene(index)`** index is REQUIRED (-1 = end); `create_midi_track/create_audio_track` index is optional; `create_return_track()` takes no index. `duplicate_track/duplicate_scene` return **None**.
8. **`Clip.quantize(grid, amount)`**: grid is an int; Ableton passes `Live.Song.RecordingQuantization` values (e.g. `rec_q_sixtenth`) with amount 1.0.
9. **Live 12-only extras** (not in 11.0): `DeviceParameter.display_value`, `Clip.sample_rate`, `Clip.is_session_clip`, `Song.scale_mode`, `Scene.tempo_enabled`, `Clip.get_all_notes_extended`, `Clip.duplicate_notes_by_id`, `Track.take_lanes`. `Song.root_note`/`scale_name` and the whole `*_notes_extended`/`add_new_notes` API are Live **11.0+** (absent from 10.1.19).
10. **`Sample.gain_display_string()`** is a METHOD (on Clip it is a property).
11. **`browser.load_item(item)`** takes only the item -- it loads onto the currently selected track/hotswap target; set `song.view.selected_track` first (as ableton-mcp does).
12. **`DeviceParameter.__str__`**: not listed in any dump (dunders are not dumped); Ableton's MxDCore uses `str(parameter)` -> treat as **unclear/likely**. Prefer `param.str_for_value(param.value)` (verified) or `display_value` (12.x).
13. `_Framework.ControlSurface.song` is a **method** (`self.song()`); in `ableton.v2`/`v3` frameworks it is a **property** (`self.song`).

Nothing in the requested list was found to be non-existent in Live 12.4.
