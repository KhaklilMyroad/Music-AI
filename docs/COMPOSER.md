# מנוע ההלחנה: טראק שלם ב-MIDI, תיבה אחרי תיבה

`track2ableton.compose` כותב טראק קלאבי שלם כקובצי MIDI מתוך מפרט קצר (טמפו, סולם, מבנה): תופים, סאב ומיד-באס, אקורדים, הוק ותווי טריגר לווקאל. כל תו נכתב לפי כללים קבועים, בלי אקראיות, ואחרי הכתיבה רצות 15 בדיקות על התווים.

המנוע כותב תווים. הוא לא בוחר סאונדים, לא ממקסס ולא שומע. אם הטראק טוב או לא, את זה קובעים הסאונדים, המיקס והאוזן.

## הרצה

```bash
python -m track2ableton.compose --out "My Track" --bpm 130 --key "A minor"
```

```bash
python -m track2ableton.compose --out audition --structure loop16 --variants 3
```

```bash
python -m track2ableton.compose --out "My Track radio" --structure radio --show 33-36
```

| דגל | משמעות | ברירת מחדל |
|---|---|---|
| `--bpm` | טמפו (60–200) | 130 |
| `--key` | `"A minor"`, `"F minor"`, `"D dorian"`, `"E phrygian"`, `"D hijaz"` | A minor |
| `--progression` | `andalusian`, `minor_loop`, `dorian_vamp`, `phrygian`, `hijaz` | לפי המודוס |
| `--structure` | `extended` (200 תיבות), `radio` (97 תיבות, נחתך מה-extended ומסתיים בתיבת סיום), `loop16` (16 תיבות של הדרופ, להאזנה) | extended |
| `--variant` / `--variants N` | 0–2: פיגורות חלופיות לעץ, לבאס ולהוק. `--variants 3` כותב את שלושתן לתיקיות `v0`, `v1`, `v2` | 0 |
| `--swing` | סווינג באחוזים (50 = ישר) לכל מה שמנגן שש-עשריות אי-זוגיות: פרקשן, באס, פד והוק | 57.5 |
| `--late-ms` | כמה העורות מאחרים מאחורי הפעמה | 6 |
| `--straight-pitched` | הבאס, הפד וההוק נשארים על הגריד הישר, ורק הפרקשן בסווינג (להשוואה באוזן) | כבוי |
| `--straight` | MIDI ישר, והגרוב מוחל ב-Live. `arrangement.json` מפרט לכל ערוץ את ה-Track Delay ואת התיבות שלא אמורות לקבל סווינג | כבוי |
| `--show A-B` | מדפיס רשת טקסט של תיבות A עד B | |

## מה נוצר

```
<out>/
  MIDI/01 Kick.mid ... 18 Chant.mid   # קובץ לכל ערוץ, כולם מתחילים בתיבה 1
  MIDI/drums_gm.mid                   # כל התופים בקובץ אחד, בתווי General MIDI, ל-Drum Rack
  arrangement.json                    # קטעים, ערוצים, כלי מוצע לכל ערוץ, תוצאות הבדיקות
  REPORT.md                           # אותו מידע בעברית
```

## הכללים שהמנוע כותב לפיהם

- **מבנה:** כל קטע מתחיל בתיבה מהצורה 8n+1, והדרופים קבועים מראש (81 ו-145 ב-extended). ב-8 התיבות האחרונות של כל בילד, האנרגיה עולה בכל תיבה, הסאב וההוק בחוץ, ופעמה 4 של התיבה האחרונה ריקה, חוץ מצעקת הווקאל. הגרוב שלפני הדרופ מחזיק בחוץ את הג'מבה, את התוף הנמוך ואת שש-עשריות השייקר, כדי שלדרופ יהיה מה להוסיף.
- **תופים:** קיק על כל רבע. הקיק והקלאפ בדיוק על הגריד. עורות ועץ מובילים, המתכת דלילה ורכה. הקונגות עונות זו לזו בתוך התיבה, בצורה של שתי תיבות, והבונגו והג'מבה מתחלפים בין תיבות. משפט של 16 תיבות, שבו הכלים נכנסים בהדרגה, עם פיקאפ קל כל 8 תיבות וטרנאראונד מלא (רול שעובר מהקונגה הגבוהה לנמוכה, בלי הקיק האחרון) רק כל 16. באינטרו ובאאוטרו הקיק רציף, בשביל הדי-ג'יי.
- **תחושה:** סווינג אחד לכל הערוצים שמנגנים שש-עשריות אי-זוגיות, כדי שהבאס וההוק לא יקדימו את הפרקשן שמכפיל אותם. הקיק, הקלאפ והרול ישרים, וגם הקונגה הגבוהה כשהיא מנגנת שש-עשריות רצופות ליד הרול. העורות מאחרים בכמה מילישניות, באופן קבוע ומתוכנן. בלי טריולות.
- **באס:** תו אחד בכל רגע, ואף תו לא מתחיל יחד עם קיק. שורשי הסאב ב-41–78 הרץ. בקטעי הגרוב אוף-ביט, בדרופ זוגות של שש-עשריות בין הקיקים, ובברייק בלי תופים תו ארוך. לפני עלייה לשורש הבא יש תו מוביל מהסולם, רק כשהבאס ממשיך לנגן בתיבה הבאה. טווח הסאב הוא אוקטבה אחת, ולכן בחלק מהסולמות קו השורשים קופץ. ב-A, Bb ו-B minor הירידה חלקה, והדוח מציין את גודל הקפיצה.
- **הרמוניה:** אקורד לכל שתי תיבות, לולאה של 8 תיבות. ב-minor ברירת המחדל היא הקיידנס האנדלוסי (i–bVII–bVI–V7b9). האקורדים בפד בהולכת קולות מינימלית, בתחום 165–330 הרץ, מתחת להוק.
- **הוק:** רק בפעמות 3–4, כדי להשאיר את פעמות 1–2 לווקאל. בתיבה האחרונה של כל לולאה יש ריצה בסולם של האקורד (פריגי דומיננטי מעל ה-V). תו שמחזיק טריטון או ספטימה גדולה מול הבאס ליותר משש-עשרית מוזז לצליל האקורד הקרוב. השנייה הקטנה שמעל שורש פריגי (ה-b9 של ה-V) נשארת, כי היא הצבע הספרדי.
- **ווקאל:** הערוץ Chant מכיל רק טריגרים: C3 לצ'אנט בפעמות 1–2, D3 לצעקה לפני הדרופ. את הדגימות טוענים בעצמכם.

## ב-Ableton

1. קובעים את הטמפו, וגוררים כל קובץ לערוץ משלו, לתיבה 1.
2. כשהתחושה כתובה בתוך ה-MIDI (ברירת המחדל), **כל הקליפים צריכים Groove = None**. אחרת הפרקשן מקבל סווינג פעמיים. Live מחיל על קליפים חדשים את גרוב ברירת המחדל של הפרויקט, אם הוגדר כזה.
3. בערוצי התופים כל התווים על C3: דגימה אחת ב-Simpler לכל ערוץ.
4. ב-Operator של הסאב: Voices = 1 (ידנית).
5. רייזרים, פתיחת פילטרים ו-high-pass בבילד הם אוטומציה, והם לא חלק מה-MIDI.

אפשר גם לדחוף ישירות ל-Live הפתוח דרך הגשר:

```python
from track2ableton.compose import Spec, compose
from track2ableton.compose.live import push
from track2ableton.live.client import LiveClient

comp = compose(Spec(bpm=130, key="A minor", structure="loop16"))
print(push(comp, LiveClient().call, at_bar=201, prefix="N "))   # אחרי סוף השיר, בשמות עם תחילית
```

`push` יוצר ערוץ MIDI וקליפ ב-Arrangement לכל חלק, כותב את התווים וקורא אותם בחזרה. אם שלב נכשל באמצע, הערוצים שהוא יצר נמחקים והשגיאה מוחזרת, כך שאפשר פשוט להריץ שוב. הוא לא טוען כלים, לא מכניס ערוצים לקבוצות ולא משנה Groove.

## מה נבדק ומה לא

**נבדק** (`pytest tests/test_compose.py`): כל הסולמות, המודוסים, הווריאנטים והמבנים עוברים את 15 הבדיקות. הבודק עצמו נבדק: לכל בדיקה מוכנסת שגיאה מכוונת, והיא נתפסת. קובצי ה-MIDI נקראים בחזרה ומשווים לתווים. `push` נבדק מול Live מדומה.

**לא נבדק:**
- **איך זה נשמע.** אף אחד לא האזין לתוצאה. התבניות נכתבו לפי כללי הז'אנר ולפי מה שאושר בפרויקט AfroTech130, לא לפי האזנה.
- **Live אמיתי.** `push` נבדק רק מול הדמיה. קובצי ה-MIDI הם Standard MIDI Files רגילים.
- **מקאם.** `hijaz` הוא הקירוב ב-12 חצאי טונים (פריגי דומיננטי), לא אינטונציה אותנטית.
- מודוסים של מז'ור ומשקלים שאינם 4/4 לא נתמכים.
